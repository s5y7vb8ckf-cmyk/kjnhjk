MILO ADMIN – CSV ONLY (نسخة القراءة من رابط واحد)

هذه النسخة لا تستخدم Google Apps Script أو روابط API أخرى لجلب البيانات.
مصدرها الوحيد:
https://docs.google.com/spreadsheets/d/e/2PACX-1vRWTsbSDKAGwrI46TDK0rlwGmDy7gah_127NW-DaUzFffUFv9eK2f1X90HryjUMYU3aR8wPnK2UE_2B/pub?output=csv

العمل:
- تنشئ صفحة عرض عام مناسبة للجوال والكمبيوتر، بالألوان الأسود والأبيض والأخضر.
- تحمّل ملف CSV مباشرة في المتصفح، وتعرض الأعمدة المسموح بها فقط.
- البحث والتصفية والترتيب والتصدير من الأعمدة الظاهرة.
- تخفي أسماء المستخدمين وكلمات المرور وأرقام الجوال وحقول الهوية والعناوين من الواجهة، ولا تخزن CSV في localStorage.
- الأيقونات مضمنة في مجلد icons وتم تصحيح مسارات PWA.

ما لا يمكن تحقيقه من CSV عام:
- تسجيل دخول آمن باستخدام B و C: بيانات تسجيل الدخول المنشورة تكون مكشوفة لأي متصفح يطلب CSV.
- إضافة وتعديل وحذف المنتجات: CSV منشور للقراءة فقط.
- عرض جميع أوراق المصنف: رابط pub?output=csv يعرض ورقة منشورة واحدة.
- ضمان نجاح fetch: قد تمنع سياسة CORS على docs.google.com القراءة المباشرة في بعض البيئات.

إذا كان الرابط يعرض ورقة Accounts التي تتضمن username/password، أوقف نشر الورقة فورًا واحذف كلمة المرور العامة وأعد ضبط كلمات المرور. لا تستخدم هذه النسخة لعرض بيانات سرية.

طريقة النشر على GitHub Pages:
1- ارفع محتويات هذا المجلد إلى جذر مستودع الموقع (index.html وapp.js وstyles.css وmanifest.webmanifest ومجلد icons).
2- افتح الرابط بعد اكتمال نشر GitHub Pages، أو جرّب الموقع محليًا عبر خادم HTTP.
3- اضغط "تحديث البيانات". إذا ظهر خطأ CORS فلن يستطيع المتصفح قراءة المصدر مباشرة؛ يتطلب ذلك خدمة وسيطة موثوقة خارج شرط "CSV فقط".

تنبيه: لم يمكن التحقق من محتوى رابط CSV ولا من CORS من بيئة الإنشاء؛ الاختبار المطلوب عند نشر الموقع.
